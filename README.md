# Discord bot AI Toolkit
*Winning Submission for Cohere WISE Hackathon*

Provides tools to integrate a Discord bot in a server with Cohere's AI agent. 

### Toolkit allows AI to do the following:
- Send messages and react to messages
- Assign roles to server members 
- List server information, including member and channel information
- Create an event
- Read messages in server (used to return information such as a todo list, or for moderating)
- Kick and ban members 
- Send randomized cat gifs 

### Future improvements:
- Chat directly with the AI agent by messaging the Discord bot (two way instead of current one way communication)
